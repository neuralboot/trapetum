Trapetum for macOS (Apple Silicon, M1 or later, macOS 13 or later). Metal GPU inference, no Python.
  ./install.sh    then:  ~/.trapetum-bin/trapetum ~/.trapetum   ->  http://localhost:8088
Models: install them from the Models tab (pre-compressed files from the Trapetum registry,
checked by SHA-256), or drop <name>/{model.cbk,tokenizer.json,config.json,meta.json} under ~/.trapetum/
Privacy: see https://trapetum.neuralboot.com/privacy-policy.html for the network requests the server makes.
